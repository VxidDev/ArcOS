# Calc

Simple calculator made for ArcOS.

## Usage:
```
calc <num> <oper> <num>
```

## Supported operations:

- Addition ('+')
- Subtraction ('-')
- Division ('/')
- Multiplication ('*')

### Example:

```
calc 123 + 123
calc 123 +123
calc 123+123
calc 123+ 123
```

other operator positions are not supported.

## Output:
```
ArcOS > calc 123 + 123
246
ArcOS >
```
